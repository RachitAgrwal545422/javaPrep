MODULE 01 · FOUNDATIONS

Thread Basics

Must Know
  • Thread vs Process — memory model, context switch cost
  • Thread lifecycle — NEW → RUNNABLE → BLOCKED → WAITING → TERMINATED
  • Creating threads — extend Thread, implement Runnable, Callable
  • Thread priority & daemon threads
  • sleep() vs wait() vs yield() vs join()
💡 Asked in 90% of interviews
🔒
MODULE 02 · FOUNDATIONS

Synchronization & Locks

Must Know
  • synchronized keyword — method & block level
  • Intrinsic locks — monitor, re-entrant behavior
  • ReentrantLock — lock(), tryLock(), unlock(), fairness
  • ReadWriteLock — when reads > writes
  • StampedLock — optimistic reading
  • volatile — visibility guarantee, not atomicity
💡 Core of every concurrency question
🧠
MODULE 03 · FOUNDATIONS

Java Memory Model (JMM)

Must Know
  • Happens-before relationship
  • CPU cache & main memory — visibility problem
  • Instruction reordering by JIT/CPU
  • volatile — happens-before guarantee
  • final fields — safe publication
  • Double-checked locking — classic trap
💡 Separates good devs from great ones
⚙️
MODULE 04 · INTERMEDIATE

Executor Framework

Must Know
  • Executor, ExecutorService, ScheduledExecutorService
  • ThreadPoolExecutor — core/max pool, queue, keep-alive, handler
  • Fixed / Cached / Single / Scheduled thread pools
  • Future & Callable — get(), cancel(), isDone()
  • CompletableFuture — thenApply, thenCompose, allOf, anyOf
  • ForkJoinPool — work-stealing algorithm
💡 Must code ThreadPoolExecutor from scratch
📦
MODULE 05 · INTERMEDIATE

Concurrent Collections

High Priority
  • ConcurrentHashMap — segment locking vs CAS (Java 8+)
  • CopyOnWriteArrayList — when to use & trade-offs
  • BlockingQueue — ArrayBlocking, LinkedBlocking, PriorityBlocking
  • ConcurrentLinkedQueue / Deque
  • SynchronousQueue — handoff pattern
  • DelayQueue — scheduling tasks
💡 BlockingQueue is used in LLD Producer-Consumer
⚛️
MODULE 06 · INTERMEDIATE

Atomic Variables & CAS

High Priority
  • AtomicInteger / Long / Boolean / Reference
  • Compare-And-Swap (CAS) — hardware instruction
  • ABA problem — AtomicStampedReference fix
  • LongAdder / LongAccumulator — high-contention counters
  • VarHandle (Java 9+) — field-level atomics
💡 CAS internals are a senior-level question
🚦
MODULE 07 · ADVANCED

Synchronizers

High Priority
  • CountDownLatch — one-time gate (N → 0)
  • CyclicBarrier — reusable rendezvous point
  • Semaphore — rate limiting, resource pool
  • Phaser — dynamic party registration
  • Exchanger — bidirectional data transfer
💡 Latch vs Barrier is a classic interview trap
⚠️
MODULE 08 · ADVANCED

Classic Concurrency Problems

Must Know
  • Race condition — detection & fixes
  • Deadlock — conditions, prevention, detection
  • Livelock — threads busy but make no progress
  • Starvation — fairness policies
  • Thread confinement — ThreadLocal usage
  • Safe publication of shared objects
💡 Deadlock code fix is asked frequently
🏗️
